# M2 dependency and parameter record

M2 adds no third-party application or numerical library. C++17/Python standard
libraries, compilers, container base and signed snapshot remain those in
[M1.md](M1.md); their platform/package license distinctions still apply.
New C++/Python code, equations expressed as code, synthetic scenario parameters
and documentation are project-authored under the repository MIT license.

`src/circuit.hpp` is the bounded numerical core. It uses an at-most-16-variable
pivoted solve instead of adding a matrix package. This reduces dependency scope
but puts numerical verification and failure handling on this project; shared
compiler, math library, plant and transport remain common causes. Non-finite or
out-of-bounds results and water-residual failure abort through plant arbitration.

The two profiles in `scenarios/circuit_small.json` and `circuit_large.json` were
chosen solely as distinct synthetic fixtures. Their coefficients are neither
manufacturer data nor literature calibration, and no source dataset is bundled.
No clinical, microbiological or product specification validity range is asserted.
Exact input and dependency identities are included in each run manifest.
