# M3 dependency and model provenance

No new application library, dataset or asset is introduced. Numerical code uses
Python's standard library and project-authored three-by-three solves; platform
versions/licenses remain those in [M1.md](M1.md). All new source and synthetic
fixtures are covered by the repository MIT license.

The conceptual research references in [M3_PATIENT.md](../M3_PATIENT.md) informed
the explicit distinction between compartment transport, active ion regulation
and respiratory/acid-base chemistry. Their code, figures, tables, text and clinical
datasets are not copied or bundled. No published fitted parameter is relabeled as
project calibration. Initial concentrations, exchange/partition/refill coefficients
and external contributions in `scenarios/patient_*.json` are synthetic fixtures.

Calibration dataset: **none**. Independent model-validation dataset: **none**.
Software/numerical verification: analytic cases, conservation calculations,
synthetic scenarios and actual process/Compose integration. Reference-paper
validation claims are not claims about DialysisLab. Review triggers include any
change in species, partition/refill laws, buffer chemistry, physiological data
source, solvers or supported timestep/range. Failure must abort with retained
partial-transaction evidence; negative concentrations must not be hidden by clipping.
