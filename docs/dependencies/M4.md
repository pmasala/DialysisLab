# M4 dependency and parameter provenance

No new third-party application dependency, dataset or asset. C++17 and Python
standard-library implementation uses the pinned M1–M3 toolchain and platform
inventory. New source/fixtures are project-authored MIT material.

Reservoir volumes, concentrate vectors, heater gain, pump head, resistances,
penetration fractions and quality thresholds are synthetic demonstration
parameters. No commercial dialyzer/preparation specification or microbial data is
invented or reproduced. Two filter stages represent hydraulic losses and a
contaminant surrogate; neither filtration efficacy nor sterility is validated.
Calibration and independent validation datasets: **none**.

Review triggers: physical/chemical/thermal or quality-barrier changes, parameter
sources, solver/timestep changes, clinical interpretation or new dependencies.
See [M4 equations/limits](../M4_TREATMENT.md) and [M1 pins/licenses](M1.md).
