# M5 dependency selection

M5 introduces no third-party application dependency. The lifecycle, alarm,
device transport and external-flush code is original project MIT source.
Control/protection retain the bounded C++ standard-library/POSIX implementation;
Python patient/runner/test tools retain standard-library-only dependencies.

Build/runtime versions, signed snapshot, image digest and package-license
obligations remain as recorded in [M4](M4.md) and the retained package inventories.
Native GCC 13.3.0/CMake 3.28.3/Python 3.12.3 and container GCC 14.2.0/CMake
3.31.6/Python 3.12.14 identify the tested environment. No GUI source, font,
unreviewed dependency archive, licensed standard or extracted image is added to
Git, Docker inputs or the publication allowlist by this phase.

The shared protocol/lifecycle code is a common-cause design risk, not an
independent safety library. Container/system licensing obligations and the
complete image SBOM/security assessment remain tracked for M8; no license
exception is implicitly approved here.
